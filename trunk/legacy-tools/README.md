# Legacy IRAF / PyRAF helpers

These files are preserved installation helpers for the original PESSTO pipeline.
They are not required by the active Python 3.11 / PypeIt 3 EFOSpec runtime.

Follow [the legacy installation guide](../../docs/legacy-installation.md).
The `other_instructions/` files retain their original historical commands;
helper files formerly at the repository root now live in this directory.
