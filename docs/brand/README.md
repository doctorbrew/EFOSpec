# EFOSpec identity

- [Desktop emblem](../../src/efospec/assets/efospec-mark.png): transparent, light mint green; sits left of the EFOSpec title.
- `efospec-logo.png`: original horizontal wordmark for the README and documentation.
- `efospec-app-icon.png`: original square icon concept for future packaging.
- Symbol: an optical slit beside three spectral ribbons, forming an **E**.
- Palette: forest green, muted coral, muted blue, and warm ivory.
- Original concepts are opaque; the desktop emblem uses PNG alpha transparency.
- Generated with the imagegen tool; [saved prompts](prompts.txt).
- The native Qt app uses the transparent emblem; standalone installers remain planned.
