# EFOSpec identity

- [Current repository logo](efospec-ntt-spectrum.png): a stylized NTT enclosure above a coral spectral trace, with an azure EFOSpec wordmark. Transparent PNG, generated with the built-in imagegen tool; prompt retained privately.
- Telescope geometry is inspired by the [ESO NTT enclosure](https://www.eso.org/public/teles-instr/lasilla/ntt/); this is an original software mark, not an official ESO logo or a measured spectrum.

- [Desktop emblem](../../src/efospec/assets/efospec-mark.png): transparent spectral **E**, left of the EFOSpec title.
- Mint slit; coral, blue, and mint ribbons with gentle curves and a shorter middle arm.
- Desktop palette: mint `#9BD3B4`, coral `#EF8D86`, blue `#8DB7D2` (design targets).
- [Previous repository wordmark](efospec-logo.png): transparent PNG with azure-blue lettering/slit/bottom ribbon, coral and soft-blue accents. Colour reference: Spectypus, target `#58A6E7`.
- `efospec-app-icon.png`: original square icon concept for future packaging.
- Symbol: an optical slit beside three spectral ribbons, forming an **E**.
- Original palette: forest green, muted coral, muted blue, and warm ivory.
- Repository wordmark and desktop emblem use PNG alpha transparency; the original square icon concept remains opaque.
- Generated with the imagegen tool; original prompts are retained privately.
- The native Qt app uses the transparent emblem; standalone installers remain planned.
